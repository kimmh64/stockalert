# 주식 매매알림

보유 종목이 **고점에서 정해진 % 만큼 떨어지면 매도**,
저점에서 정해진 % 만큼 오르면 **매수** 를 알려주는 윈도우 프로그램입니다.

## 왜 만들었나

**「주식아가방」**(김어준의 겸손은힘들다 뉴스공장, 2025.9.9 · 2026.2.24)에서
광수네 복덕방 **이광수 선생님**이 말한 개별주식 투자 원칙을,
사람 손을 거치지 않고 그대로 지켜보려고 만들었습니다.

```
1. 주식시장에서는 오래 살아남아야 한다
2. 오래 살아남으려면 손해를 적게 봐야 한다
3. 살 때, 몇 % 이상 빠지면 무조건 판다는 원칙을 정한다
4. 수익이 크게 날 때는 최대한 크게 내야 한다
5. 오를 때는 절대 팔지 않는다 - 고점에서 정한 % 만큼 떨어졌을 때 판다
6. 정해놓은 원칙을 그대로 지킨다
```

> "**손실은 줄이고요, 이익을 많이 내야 합니다.** 그런데 보통 주식투자를 어떻게 하시냐면
> **손실을 늘리고, 이익을 줄이는** 투자를 하고 있습니다"
>
> "**예측은 단 한 번만 하는 겁니다, 살 때요.** 그다음에는 대응하는 영역이에요"
>
> "**주가가 오르는 주식은 절대 파는 게 아닙니다**"

어려운 것은 **6번**입니다. 원칙은 살 때 정하지만, 지켜야 하는 순간은 팔 때입니다.
그때는 오르면 더 오를 것 같고, 내리면 곧 돌아올 것 같습니다.

그래서 이 프로그램은 **정해둔 원칙을 대신 지켜보고 알려주기만** 합니다.

| 원칙 | 프로그램이 하는 일 |
|---|---|
| 손해는 적게 | 고점에서 정한 % 만큼 빠지면 **매도 알림** |
| 수익은 크게 | **오르는 동안에는 아무 말도 하지 않습니다** |
| 살 때 정한다 | 살 때 판정값을 넣어둡니다 |
| 그대로 지킨다 | 매일 종가로 확인해 카톡으로 알립니다 |

> 몇 % 로 할지는 정해져 있지 않습니다. 감당할 수 있는 선이 사람마다 다르니
> **스스로 정하라**는 것이 이광수 선생님의 이야기입니다.
> 그 숫자를 직접 찾아보는 것이 아래 **[최적 판정값 찾기]** 입니다.

<sub>개인이 만들어 공개하는 프로그램입니다. 이광수 선생님 및 광수네 복덕방과
아무런 관련이 없으며, 추천이나 감수를 받지 않았습니다.</sub>

## ⚠ 이 프로그램은 손해를 덜 보게하는 프로그램입니다

8종목 × 5구간 = 40가지 경우를 실제 과거 시세로 돌려봤습니다.
규칙대로 사고팔았을 때 **그냥 들고 있는 것보다 나았던 경우는 42% 뿐**이었습니다.
상승장에서는 조정마다 팔렸다가 더 비싸게 다시 사게 되어 수익을 반납합니다.

**대신 하락장에서는 확실히 덜 잃습니다.**

| 2022년 하락장 | 규칙대로 | 그냥 보유 |
|---|---|---|
| 카카오 | **−9.3%** | −53.6% |
| 삼성전자 | **−14.4%** | −29.6% |

그래서 이 프로그램의 목적은 하나입니다 — **크게 물리는 것을 피하는 것.**
"수익률을 올려준다"고 말하지 않겠습니다. 그건 사실이 아닙니다.

## 무엇을 해주나요

```
매수하면 그 매수가가 기준(직전최고가)이 됩니다
주가가 오르면 기준도 따라 올라갑니다  (내려갈 때는 안 내려갑니다)
기준에서 정해진 % 만큼 떨어지면  →  "매도필요" 알림
```

- 장 마감 후 **종가가 확정되면 자동으로** 판정합니다 (평일)
- 안 팔거나 안 사고 계시면 **매일** 내 카톡으로 다시 알려드립니다
- 나눠서 여러 번 사셨으면 **매매건별로 따로** 관리합니다
- 정한 시각에 **하루 한 번 시세**를 내 카톡으로 알려드립니다
- 며칠 꺼두셨어도 다시 켜면 **밀린 거래일을 따라잡아** 확인합니다

> 장중에는 신호를 내지 않습니다. 실측 결과 장중에 판정하면 12건 중 11건에서
> 성과가 나빠졌습니다. 잠깐 흔들릴 때마다 팔리기 때문입니다.

## 처음 쓰실 때

1. 안내 창에서 **[동의하고 시작]**
2. **[설정] → [카톡 알림 켜기]** — 카카오 로그인 한 번이면 끝입니다
   (개발자 가입도, 키 발급도 필요 없습니다)
3. **[종목 추가]** — 종목명 일부·초성·코드 모두 됩니다 (`삼성` `ㅅㅅㅈㅈ` `005930`)
4. **[매매 입력]** — 매수한 날짜와 금액(1주당).
   ⚠️ **이걸 해야 매도·매수 신호 카톡이 옵니다**
5. **[판정값 변경]** — 몇 % 로 알릴지 정합니다.
   잘 모르시면 기본값 그대로 두셔도 됩니다 → 아래 **[최적 판정값 찾기]** 참고
6. **[설정] → 윈도우 시작 시 자동 실행** 을 켜 두면 PC 를 켤 때마다 알아서 돕니다

## 용어 정의

| 말 | 뜻 |
|---|---|
| **판정값** | 몇 % 움직이면 매도 매수 신호를 알릴지. 매도 판정값 10% = 고점에서 10% 빠지면 알림 |
| **직전최고가** | 매수한 뒤 찍은 가장 높은 값. 매도 판정의 기준 |
| **직전최저가** | 매도한 뒤 찍은 가장 낮은 값. 매수 판정의 기준 |
| **매도선 / 매수선** | 실제로 신호가 나는 가격(원) |
| **보유중 / 매도필요** | 들고 있는 중 / 팔라는 신호가 난 상태 |
| **관망중 / 매수필요** | 안 들고 있는 중 / 사라는 신호가 난 상태 |

**신호가 나도 프로그램이 상태를 바꾸지 않습니다.** 실제로 사고팔았을 때
**[매매 입력]** 을 해주셔야 확정됩니다. 그때까지는 매일 다시 알려드립니다.

기본 판정값은 **매도 −10% / 매수 +15%** 이고, 10% 미만은 넣을 수 없습니다.
10% 미만으로 하면 조금만 흔들려도 알림이 쏟아지고, 실측에서 방어력도 오히려 나빴습니다.

# ⭐ 최적 판정값 찾기

**이 프로그램에서 가장 공들인 기능입니다.**
"내 종목은 몇 %로 잡아야 할까" 를 과거 시세로 직접 확인해 보는 창입니다.

### 무엇을 하나요

종목과 기간과 판정값을 넣으면, **그때 그 규칙대로 사고팔았다면 어땠을지** 계산해서
매매 하나하나를 보여줍니다. 판정값을 여러 개 넣어 나란히 비교할 수 있습니다.

```
삼성전자  20230817~20260814 (728거래일)     그냥 보유했다면 +311.54%

 판정값                        수익률     매매     참고
 매도 -20%  /  매수 +15%      +347.71%   4회전
 매도 -10%  /  매수 +15%       +91.30%  12회전
 매도 -20%  /  매수 +20%      +330.61%   4회전

매매 내역  -  매도 -10%  /  매수 +15%
   수익 4건 평균 +49.9%   ·   손실 8건 평균 −10.9%
   매수 20230817  66,700원  →  매도 20240117  71,000원     +6.4%
   ...
```

### 어떻게 쓰는 게 좋은가

**① [최악 구간] 버튼부터 눌러보세요**

`3개월` `6개월` `9개월` `1년` — 최근 5년에서 **그 종목이 가장 많이 빠진 구간**을
찾아 기간에 넣어줍니다.

이 프로그램의 목적이 "큰 하락 피하기" 이므로, **가장 나빴던 때 얼마나 방어했는지**가
가장 중요합니다. 좋았던 장에서는 어떤 값이든 그럭저럭 나옵니다. **갈리는 건 하락장입니다.**

**② 매매 요약을 보세요**

```
수익 4건 평균 +49.9%   ·   손실 8건 평균 −10.9%
```
12번 사고팔아 **4번만 수익이 났는데 총 +91%** 입니다. 자주 손실이 나지만 수익이 날 때 크게 법니다.
이 방식은 원래 그렇게 법니다. 그래서 *"수익이 난 횟수가 적네"* 는 판단 기준이 아닙니다.

**③ 맨 윗줄은 프로그램이 얹은 것입니다**

내가 넣지 않은 줄이 하나 보이면, **그 기간에서 수익률이 가장 높았던 조합**입니다.
16가지를 다 돌려 1등을 올려놓은 것뿐입니다. **추천이 아닙니다** — 아래 함정을 보세요.

**④ "표본 적음" 이 붙으면 믿지 마세요**

매매가 3회전 미만이면 붙습니다. 그때 판정값끼리의 차이는 **매매 한두 번의 차이**라
우연일 수 있습니다. 여러 종목에서 같은 결론이 나오는지 보는 편이 확실합니다.

### ⚠️ 가장 중요한 함정 — 과거에 맞았던 값이 앞으로도 맞지는 않습니다

과거에 딱 맞는 숫자를 찾을수록, 그건 **그 기간에만 맞는 숫자**가 됩니다.

### 그래서 이렇게 쓰시길 권합니다

```
✗  이것저것 돌려서 제일 높은 값을 고른다
⭕  최악 구간에서 크게 무너지지 않는지 확인한다
⭕  여러 종목·여러 기간에서 두루 무난한 값을 고른다
```

### 계산에 쓰인 전제

- 신호가 난 **그날 종가에 사고판 것**으로 계산합니다.
  실제로는 종가를 보고 판단하므로 다음 거래일에 매매하게 됩니다 — **그만큼 실제보다 좋게 나옵니다**
- **수수료·세금·배당은 넣지 않았습니다.** 매매가 잦은 판정값일수록 실제와 더 벌어집니다
- "그냥 보유" = 기간 첫날 종가에 사서 마지막날까지 그대로 둔 것
- 매매로 늘고 준 돈이 다음 매매에 그대로 반영됩니다 (복리)

## 자주 묻는 것

**Q. 자동으로 사고파나요?**
아니요. **알림만** 드립니다. 매매는 직접 하셔야 합니다.

**Q. 제 정보가 어디로 가나요?**
아무 데도 안 갑니다. 서버가 없습니다. 종목·매매 기록은 **내 PC에만** 저장됩니다.
카카오톡 알림도 각자 본인 계정으로 본인에게 보내는 것입니다.

**Q. 컴퓨터를 며칠 꺼두면 그 사이 신호를 놓치나요?**
아니요. 다시 켜면 **밀린 거래일을 순서대로 따라잡아** 확인합니다.

**Q. 미국 주식도 되나요?**
아직 국내 주식(코스피·코스닥·ETF)만 됩니다.
