# 주식 매매알림

보유 종목이 고점에서 정해진 % 만큼 떨어지면 **매도**,
저점에서 오르면 **매수** 를 알려주는 윈도우 프로그램입니다.

<br>

## ⬇  [ 프로그램 내려받기 (StockAlert.zip) ](https://github.com/kimmh64/stockalert/releases/latest/download/StockAlert.zip)

### ↑ 위 파란 글씨를 누르면 바로 받아집니다
설치 필요 없습니다. **압축을 풀고** `주식매매알림.exe` 를 실행하세요.

<br>

---

## ⚠ 받을 때 경고가 뜨는 것은 정상입니다

서명 인증서가 없는 개인 제작 프로그램이라 브라우저와 윈도우가 경고를 냅니다.
바이러스가 발견됐다는 뜻이 아닙니다.

| 언제 | 어떻게 |
|---|---|
| 크롬이 막을 때 | 오른쪽 위 **다운로드 아이콘(↓)** → **[계속]** 또는 **[유지]** |
| 실행할 때 | "Windows의 PC 보호" → **[추가 정보]** → **[실행]** |
| 백신이 잡을 때 | 예외로 등록 |

자세한 내용은 압축 안의 **사용안내.txt** 를 읽어주세요.

---

## 무엇을 해주나요

- 평일 **오후 4시**에 그날 종가로 판정해서 알려줍니다
- 매수하면 그 **매수가가 기준(직전최고가)** 이 되고, 주가가 오르면 기준도 따라 올라갑니다
- 안 팔거나 안 사고 계시면 **매일** 다시 알려드립니다
- 나눠서 여러 번 사셨으면 **매매건별로 따로** 관리합니다
- **카카오톡 알림** — 카카오 로그인 한 번이면 끝입니다
- 윈도우 시작 시 자동 실행

## 처음 쓰실 때

1. 안내 창에서 **[동의하고 시작]**
2. **[종목 추가]** — 종목명 일부·초성·코드 모두 됩니다 (`삼성` `ㅅㅅㅈㅈ` `005930`)
3. **[매매 입력]** — 매수한 날짜와 금액(1주당). **이걸 해야 알림이 나옵니다**
4. (원하시면) **[설정] → [카톡 알림 켜기]**

## 지우고 싶을 때

**[설정] 옆 [프로그램 삭제]** 에서 지울 항목을 고를 수 있습니다.
프로그램만 지우면 매매 기록이 남아 다시 설치해도 이어서 쓰실 수 있습니다.

이 프로그램은 수익을 키우는 도구가 아니라 **큰 하락을 피하는** 도구입니다.
상승장에서는 그냥 들고 있는 것보다 수익이 낮을 수 있습니다.
